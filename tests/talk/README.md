# 无插件实时对讲验收

`node --test tests/talk/audio.test.mjs` 验证 G.711 样本、全部码字及 44.1k/48k 等采样率跨128采样块的连续重采样。

`npx vite --config tests/talk/vite.config.ts` 启动独立浏览器验收页 `http://127.0.0.1:5187/tests/talk/`。此页只使用生产 `useBrowserTalk`，不会挂载预约或检测流程；当前代理目标为现场后端。需登录 token，不能直接在未授权的生产设备上运行。

验收时确认：麦克风授权、开始/结束双向声音、拒绝授权提示、取消等待中的权限请求、关页后重新连接、第二终端不抢断、手机/平板尺寸与后台音频暂停。检查 `microphoneBytes` 和 `receivedBytes` 均持续增长。音频工程诊断仅在此测试页展示。

现场实际使用入口为受信任的 HTTPS 5174。生产预约窗口与主页独立可视对讲均复用同一模块，不依赖海康 Windows 插件。浏览器测试使用模拟麦克风时，应明确记录；平板模拟不能代替真实设备听说验收。
